设备通信

仅 USB

USB 始终用于配置和烧录。无线只发送已识别的动作；不确定的动作不会发送。

配置 Wi-Fi / MQTT / 蓝牙

本版使用局域网 MQTT/TCP。更改配置时请重新填写密码；密码不回显、不写入调试日志。

BLE 使用自定义 GATT 服务发送动作通知，不是蓝牙键盘。手机或接收端需按仓库中的协议接收。
