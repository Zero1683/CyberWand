# 常见问题

**插 Type-C 没反应**：先确认电池或 J2 电源和 SW1，Type-C 不供本板主电源。换确认可传数据的线，检查系统设备列表。原生 USB 应是 ESP32 设备，不能选择 FT232。

**端口被占用**：断开旧网页或串口监视器。一个服务独占串口，多个网页服务不能同时连接。端口号换电脑会变，不要求必须 COM30。

**代码 43 / 设备描述符失败**：不能简单归因于“没装固件”或“没驱动”。先检查供电、USB 接线和焊接，再尝试 BOOT+RESET 进入 ROM 下载模式。历史故障曾涉及 EN 和启动脚锡桥。

**网页一直未校准**：把板子放平且不动，等约两秒，或点校准。持续失败看 IMU 状态、I²C 错误、电源和焊接，不靠反复烧录掩盖硬件故障。

**录不了**：选择类别后点击“录下一份”，等准备结束再动作；拒绝或超时后重新点击。每类最多三份，需要重录时先清除该类。录入结束停留在录入模式，不会自动切到识别。

**识别总是 --**：至少训练两个不同类别，点击进入自动识别；固定握姿、拿稳、做完整动作、再次停稳。未知/拒绝动作仍显示 --，看历史记录的原因。不要通过盲目放宽阈值换取表面“都能识别”。

**手机是一串值**：BLE 通知是 16 字节二进制；使用接收脚本解码，或读取 JSON 特征。通知不是系统串口或蓝牙键盘。

**无线保存后断开**：设备重启属正常流程，等待重连，必要时重新选择 USB 端口。修改 MQTT 时空密码会被当作空密码提交。

**模板丢了/新板没有动作**：发行应用镜像不含个人模板；新板重新录入。不要为了恢复连接就整片擦除 Flash。网页导出是当前测试记录，不是全部模板的恢复备份。

**找不到 Python / 安装失败**：Python 需 3.10+，Windows 检查 PATH。首次安装需要网络；错误保留在终端。不要只打开 `index.html`，必须启动配套 Python 服务。
